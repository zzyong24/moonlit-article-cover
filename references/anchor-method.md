- 该仓库**没有许可证文件**（GitHub API `license: null`），默认保留全部权利。所以这里只吸收思路，用我们自己的话重写，没有复制它的提示词、文案、示例图或配色表。成图里也不出现「波妞」「PONYO」等作者标记（对方也是这样要求的）。
- 我们改了什么：平台从小红书竖图改成文章横幅（X 5:2、公众号 2.35:1 + 1:1）；去掉人像模板（月明规定文章封面不用人像）；配色用我们自己定的「亮橙 #E8551F + 深黑蓝 #0B1A2E」爆款配色（2026-10-21 月明选定 A 版），不用它的红黑；安全区按两平台的遮挡和裁切重新定。

## 两个变量

封面能不能被点开，主要看两件事：

1. **信息密度**：缩略图里能不能一眼看清「对我有什么用」。靠一句短承诺，不靠堆字。
2. **视觉锚点**：画面里有没有一个让眼睛停住的位置。只能有一个主锚点；元素分量都差不多，就等于没有锚点。

## 五件套

| 件 | 作用 | 规则 |
|---|---|---|
| 承诺（主标题） | 说清利益点或判断 | 6–14 字，左上起排，最重的字重 |
| 重点词 | 让标题自己带一个停点 | 只挑 1 个词上强调色，可加笔刷下划线 |
| 钩子胶囊 | 给出「凭什么点」 | ≤16 字，圆角胶囊，强调色底配白字或白底配强调色边 |
| 主锚点（右侧示意物） | 画面唯一的视觉停点 | 2–3 张卡片、关系图或物件，中间那张最大 |
| 指向标记 | 把视线从示意物引到重点 | 靶心、光标、箭头三选一，只用一个 |

## 视线与位置

- 人眼大致按「左上 → 右上 → 左下 → 右下」扫。横幅最强的位置是左上和上半部横向中段，所以主标题放左上，示意物放右侧中部。
- 文章横幅比竖图宽，左右两块要大致平衡：左边文字块约占宽度 45%–55%，右边锚点约占 35%–45%，中间留缝。
- 最重要的东西不要放在会被遮挡或裁掉的位置：X 的左下角有「X 文章」标签；公众号的 1:1 方图只保留左侧一块。

## 字重与对比

- 视觉分量：主标题约 60–75%，胶囊和副标题 20–30%，署名和标签 5–10%。
- 对比度：主标题对底色至少 4.5:1，缩略图场景争取 7:1 以上。
- 缩略图测试：缩到平台卡片宽度（X 约 520 px、公众号约 300 px）不放大能读清主标题；更小的方图（约 100 px）至少认得出重点词。

## 常见毛病与改法

| 毛病 | 原因 | 改法 |
|---|---|---|
| 好看但不想点 | 承诺太虚，标题是口号 | 改成具体判断或利益点 |
| 字多没重点 | 没有主锚点 | 删到只剩一组示意物并放大 |
| 两个东西抢眼 | 胶囊或标签过重 | 缩小胶囊，降一级字重 |
| 像 PPT 说明页 | 版面在解释，不是在吸引 | 删掉段落，只留五件套 |
| 缩略图糊成一片 | 浅色字、细字 | 加深文字、换 Black 字重、加大字号 |

## 诊断旧封面（可选流程）

给出旧封面时，按 1–10 分打五项：信息密度、视觉锚点、缩略图可读、色彩对比、可信度。写一句主要问题，列 3 条改法，再按五件套出新 brief。
